Contributing to Andrinux

Thank you for your interest in contributing to Andrinux!

How to Contribute

1. Fork the repository.
2. Create a new branch for your changes.
3. Make your changes and test them.
4. Commit your changes with a clear commit message.
5. Open a Pull Request.

Bug Reports

When reporting a bug, please include:

- Android device model
- Android version
- Steps to reproduce the issue
- Expected behavior
- Actual behavior
- Relevant logs or screenshots, if available

Feature Requests

Please explain the problem your feature would solve and describe your proposed solution.

Code Guidelines

- Use Kotlin for Android application development.
- Follow existing project conventions.
- Write clear and maintainable code.
- Add comments where they improve understanding.
- Test changes before submitting a Pull Request.

Licensing

By contributing to Andrinux, you agree that your contributions will be distributed under the project's GPL-3.0-or-later license.

Thank you for helping improve Andrinux!

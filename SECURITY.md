Security Policy

Supported Versions

Security updates are provided for the latest stable release of Andrinux.

Older versions may not receive security fixes.

Reporting a Vulnerability

If you discover a security vulnerability, please report it privately whenever possible.

Do not publish sensitive vulnerability details in public issues before a fix is available.

You can report vulnerabilities through GitHub's private vulnerability reporting feature, if enabled for this repository.

Please include:

- A description of the vulnerability.
- Steps to reproduce it.
- Potential impact.
- Relevant logs or proof of concept, if available.

Security Principles

Andrinux aims to:

- Verify downloaded files using cryptographic hashes when available.
- Use HTTPS for network downloads.
- Safely extract archives and prevent path traversal.
- Treat imported Linux root filesystems and container images as untrusted input.
- Avoid unnecessary Android permissions.
- Keep bundled third-party components updated.

Thank you for helping keep Andrinux secure.
